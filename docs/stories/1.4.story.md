### Testing Strategy Requirements

[Source: architecture/testing-strategy.md]

**Test Distribution and Organization:**

```text
Testing Pyramid:
         E2E Tests (10%)
        /              \
   Integration Tests (20%)
  /                      \
Component Tests (35%)    Game Logic Tests (35%)
```

**Test Organization Structure:**

```text
__tests__/
├── components/          # Component tests (35% of testing)
│   ├── game/           # Game-specific component tests
│   ├── ui/             # Generic UI component tests
│   └── themed/         # Theme-aware component tests
├── hooks/              # Custom hook tests
├── stores/             # Zustand store tests (game logic - 35%)
├── services/           # Service layer tests
├── utils/              # Utility function tests
└── integration/        # Integration tests (20%)
```

**Jest Configuration Requirements:**

[Source: architecture/testing-strategy.md#test-configuration]

```javascript
module.exports = {
  preset: 'jest-expo',
  transformIgnorePatterns: [
    'node_modules/(?!((jest-)?react-native|@react-native(-community)?)|expo(nent)?|@expo(nent)?/.*|@expo-google-fonts/.*|react-navigation|@react-navigation/.*|@unimodules/.*|unimodules|sentry-expo|native-base|react-native-svg)',
  ],
  setupFilesAfterEnv: ['<rootDir>/jest.setup.js'],
  collectCoverageFrom: [
    'components/**/*.{ts,tsx}',
    'hooks/**/*.{ts,tsx}',
    'services/**/*.{ts,tsx}',
    'stores/**/*.{ts,tsx}',
    'utils/**/*.{ts,tsx}',
    '!**/*.d.ts',
    '!**/node_modules/**',
  ],
  coverageThreshold: {
    global: {
      branches: 80,
      functions: 80,
      lines: 80,
      statements: 80,
    },
  },
  testEnvironment: 'jsdom',
};
```

### Testing Standards Compliance

[Source: architecture/coding-standards.md#testing-standards]

**Test Organization Requirements:**

- Use describe blocks for grouping related tests
- Descriptive test names using "should" format
- Proper setup and teardown with beforeEach/afterEach
- Mock external dependencies using jest.mock()
- Use typed mocks with `jest.MockedFunction<typeof service>`

**Test File Naming:**

- Components: `ComponentName.test.tsx`
- Hooks: `useHookName.test.ts`
- Services: `serviceName.test.ts`
- Utils: `utilityName.test.ts`

- Animation libraries (React Native Reanimated)
