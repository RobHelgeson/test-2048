- **Android Distribution**: Google Play Store via Play Console

- **Development Builds Platform**: EAS Build development profiles
- **Development Distribution**: Internal testing via EAS Development Client
- **Web App Deployment**: Vercel (recommended) or Netlify

[Source: architecture/unified-project-structure.md]

- `babel.config.js` - Babel transpilation configuration

Build output and configuration locations:

- `/dist/` - Web export output directory (auto-generated)

Platform-specific requirements:

- iOS builds require Apple Developer account configuration

- Web builds use standard Expo export process
