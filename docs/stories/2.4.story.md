### Error Handling and Validation

**Score System Error Handling:**

```typescript
const updateScore = async (points: number) => {
  try {
    // Validate score input
    if (points < 0 || !Number.isInteger(points)) {
      throw new Error('Invalid score value');
    }

    // Update score state
    dispatch({ type: 'UPDATE_SCORE', payload: points });

    // Persist to database
    await storageService.saveBestScore(newScore);

    // Update statistics
    await storageService.updateStatistics(gameResult);
  } catch (error) {
    console.error('Score update failed:', error);
    // Revert optimistic updates
    dispatch({ type: 'REVERT_SCORE_UPDATE' });
    // Show user-friendly error without breaking gameplay
  }
};
```

**Validation Requirements:**

- All score values must be non-negative integers
- Statistics calculations must handle division by zero for averageScore
- Best score updates must verify new score exceeds current best
- Database persistence failures must not break game flow
