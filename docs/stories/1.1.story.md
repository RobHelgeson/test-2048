### Architecture Context

[Source: architecture/tech-stack.md]

- **Primary Framework**: Expo SDK 53.0.20 with React Native 0.76+
- **Language**: TypeScript 5.3+ for type-safe development
- **Navigation**: Expo Router v3.5+ for file-based routing
- **Development Tools**: Expo Dev Client 2024.12+ for enhanced development experience
- **Build Tool**: Metro 0.83+ as the bundler

### Project Structure Requirements

[Source: architecture/unified-project-structure.md]
The project must follow Expo's unified structure:

```
test-2048/
├── app/                    # Expo Router file-based routing (REQUIRED)
├── components/            # Reusable UI components (Expo convention)
├── hooks/                # Custom React hooks (Expo convention)
├── stores/               # Zustand state stores
├── services/             # Business logic services
├── types/                # TypeScript type definitions
├── constants/            # Application constants (Expo convention)
├── utils/                # Utility functions
├── assets/              # Static assets (Expo convention)
├── __tests__/           # Test files
```

### Configuration Standards

[Source: architecture/coding-standards.md]

- **Import Order**: React imports, third-party libraries, local imports with @/ aliases
- **Naming Conventions**: PascalCase components, camelCase hooks/services, SCREAMING_SNAKE_CASE constants
- **File Structure**: Components in .tsx, hooks/services in .ts, strict TypeScript mode required

### Development Environment Requirements

- Hot reload must be functional across iOS, Android, and web platforms
- TypeScript error checking must be immediate in development environment
- ESLint and Prettier integration required for consistent code quality

### Git Configuration

Standard conventional commit format with proper .gitignore for Expo projects including:

- .expo/ directory exclusion
- node_modules/ exclusion
- Build artifacts exclusion
