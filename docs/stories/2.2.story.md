### Game Algorithm Implementation Details

**2048 Game Rules (Critical Implementation Requirements):**

1. **Movement Rules:**
   - Tiles slide as far as possible in chosen direction
   - Tiles stop when hitting board edge or another tile
   - Empty spaces are filled by sliding tiles

2. **Merging Rules:**
   - Only tiles with identical values can merge
   - Each tile can only merge once per move
   - Merged tile appears in destination position
   - Score increases by value of merged tile

3. **Spawning Rules:**
   - New tile appears after each successful move
   - 90% probability of spawning value 2
   - 10% probability of spawning value 4
   - Always spawns in random empty position

4. **Win Condition:**
   - Game is won when any tile reaches value 2048
   - Player can choose to continue playing after winning

5. **Game Over Condition:**
   - Game ends when no valid moves remain
   - Occurs when board is full and no adjacent tiles can merge
