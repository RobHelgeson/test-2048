# Test 2048 Project Overview

## Purpose
Test 2048 is a cross-platform 2048 puzzle game built with Expo SDK 53+ and React Native. It serves as a comprehensive learning project for modern mobile development, targeting iOS, Android, and web platforms from a single codebase.

## Technology Stack
- **Frontend:** React Native 0.79.5 with New Architecture (bridgeless mode) enabled
- **Framework:** Expo SDK 53.0.22 with EAS Build
- **Language:** TypeScript 5.8.3 with strict mode
- **State Management:** Zustand 5.0.8 for lightweight global state
- **Navigation:** Expo Router v5.1.5 with typed file-based routing
- **Animations:** React Native Reanimated 3.17.4 with native driver
- **Gestures:** React Native Gesture Handler 2.24.0 for touch interactions
- **Testing:** Jest 29.7.0 + React Native Testing Library
- **Development:** React 19.0.0, React Native 0.79.5

## Key Features
- Cross-platform (iOS, Android, Web) 2048 puzzle game
- Modern React Native New Architecture for enhanced performance
- File-based routing with Expo Router
- Local game persistence (SQLite ready)
- Touch gestures and keyboard controls
- Theme system with dark/light modes
- Comprehensive testing suite
- EAS Build integration for deployment

## Learning Focus
This project prioritizes educational value in:
- Expo ecosystem mastery through practical implementation
- React Native patterns and performance optimization
- Cross-platform development considerations
- Complete deployment pipeline from development to production
- Modern React Native architecture patterns with New Architecture
